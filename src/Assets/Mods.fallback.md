# Installation

RenoDX works as an addon for ReShade, meaning it uses ReShade's hooks and functions to dig deep into a game in order to inject rewritten shaders and more.

* Install [Reshade 6.7.3+ with full add-on support](https://reshade.me/downloads/ReShade_Setup_Addon.exe). No shaders necessary. Select the game executable which is usually found by the installer, or pick the executable manually. If installing against Xbox, target `gamelaunchhelper.exe`.

* Download the addon file from the list below by clicking the Snapshot/Nexus/Discord badges.

* Copy the `.addon64` or `.addon32` file into the game folder where Reshade is installed.

All done! When you boot up the game, RenoDX can be customized by opening the ReShade menu with the Home key.

_

**Specific installation instructions can be present on NEXUSMODS pages.** **Related HDR mods are present at the bottom of the List.** 

⚠️⚠️  **If you have a washed out image, disable AUTOHDR and RTX HDR to avoid double tonemapping** ⚠️⚠️

You can join the RENODX Discord where the mods are being developed by clicking [HERE.](https://discord.com/invite/renodx)

*Note: Snapshot builds may not be stable but are more up to date than NEXUSMODS counterparts.*

*Warning for Linux users: Using DLSS and RenoDX together with Wayland HDR can crash some games. Using gamescope, disabling nvapi with PROTON_DISABLE_NVAPI=1 and/or trying a nightly build of ReShade can mitigate issues for now.*

### Unreal Engine [![Snapshot](https://img.shields.io/github/last-commit/clshortfuse/renodx?path=src%2Fgames%2Funrealengine&label=Snapshot)](https://clshortfuse.github.io/renodx/renodx-unrealengine.addon64)

> [!TIP]
> **🚀 DLSSFIX Addon for Transformer DLSS Frame Generation / Multi-Frame Generation** [![Snapshot](https://img.shields.io/github/last-commit/clshortfuse/renodx?path=src%2Faddons%2Fdlssfix&label=Snapshot)](https://github.com/clshortfuse/renodx/releases/download/snapshot/renodx-dlssfix.addon64)
>
> Use this addon if:
> - DLSS Frame Generation flickers
> - Multi-Frame Generation behaves incorrectly
> - UE5 games exhibit odd DLSS FG artifacts
>
> **Installation**
>
> Open `ReShade.ini` and add:
>
> ```ini
> [ADDON]
> LoadFromDllMain=renodx-dlssfix.addon64
>
> [RENODX-DLSSFIX]
> DLSSPath=C:\my_game\the_dlss_folder\nvngx_dlss.dll
> StreamlinePath=C:\my_game\the_streamline_folder\sl.interposer.dll
> ```
>
> Replace the example paths above with the actual locations of:
> - `nvngx_dlss.dll`
> - `sl.interposer.dll`
>
> The addon is primarily intended for newer Transformer-based DLSS FG/MFG implementations.
---
> [!WARNING]
> **⚠️⚠️ UNREAL ENGINE MOD WARNINGS ⚠️⚠️**  
>  
> **🖥️ Black Screen on Launch**  
> Upgrade **`R10G10B10A2_UNORM` → `output size`**  
>  
> 🔓 Unlock upgrade sliders by switching **Settings Mode** from *Simple* → *Advanced*.  
> Then restart the game for the upgrade to take effect.
>
> **🖥️ DLSS FG not working properly (Flickering or other odd behavior)**  
> use [DLSSFIX addon](https://github.com/clshortfuse/renodx/releases/download/snapshot/renodx-dlssfix.addon64) or Replace DLSSG DLL to the older 3.8.x version (older dll locks you to FG x 2)

> [!NOTE]
> **🎮 Unreal Engine 5 Slider Behavior**  
> In most **UE5 games**, sliders only apply when changing scenes or going back to the main menu — **even if this is not mentioned in the per-game notes.**   
>  
> They typically take effect when:  
> • 🔄 Loading a save / changing scenes  
> • 🔄 Adjusting graphics settings  
> • ↩️ Returning to the main menu

> [!WARNING]
> **⚠️⚠️ UNITY ENGINE MOD WARNINGS ⚠️⚠️**
>  
> If limited to **BT.709** (even with saturation cranked to max), Upgrade **`R11G11B10_FLOAT`**.
>
> 🔓 Unlock upgrade sliders by switching **Settings Mode** from *Simple* → *Advanced*.
> Then restart the game for the upgrade to take effect.  
---

> [!NOTE]
> • 🚫 Avoid Exclusive Fullscreen Mode  
> • :sunny: Game's brightness/contrast/gamma setting should be set to default in most cases  
> • 💥 Crash when using XeSS → update **`libxess.dll`** in the game folder  (latest available [here](https://github.com/intel/xess/raw/refs/heads/main/bin/libxess.dll))
